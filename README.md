# North Pure Arabica — Static export coffee website

Open `index.html` in any modern browser. It is a responsive, English-language website inspired by the user-provided Web Ekspor reference and focused on Aceh Gayo Arabica.

## Pages
- `index.html` — landing page, origin, company information, journal and inquiry form
- `articles/*.html` — three complete English-language educational articles
- `assets/` — styles, scripts, brand emblem extracted from the user-supplied PDF and fallback landscape illustration

## Deploy
Upload the contents of this folder to your hosting public directory or to any static hosting service (Netlify, Cloudflare Pages, GitHub Pages). On WordPress, integrate the HTML into a custom theme; the ZIP is a standalone static site, **not** an installable WordPress theme.

## Important before launch
- Inquiry form opens the visitor’s email app (`mailto:`); no message is stored by a backend. WhatsApp link is functional. Add a verified server-side form endpoint if direct submission is required.
- Images are **real photos**, not AI-generated. They are loaded from Wikimedia Commons over the internet (internet is required; a local illustration is included as a CSS fallback). Credits and Creative Commons BY-SA 4.0 attribution are on the home page. Some backgrounds are cropped to fit the design. Replace with photos of your actual product and farms for more credible commercial marketing.
- Confirm actual offered grades, specs, available quantities, certificates, pricing, locations, and export terms. No unsupported certifications, awards or export experience are asserted.
- Set a real domain and canonical URL before enabling a public sitemap; URLs are currently relative.
- Business WhatsApp and email are taken from the provided brief.
